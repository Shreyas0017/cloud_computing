First, I downloaded the Ubuntu ISO file from the official Ubuntu website. After that, I installed and opened Oracle VirtualBox on my computer.

Then I clicked on New to create a new virtual machine. I named the machine Ubuntu and selected Linux as the operating system and Ubuntu (64-bit) as the version.

After that, I allocated 8 GB of RAM to the virtual machine and created a virtual hard disk of around 90 GB.

Next, I went to Settings → Storage and selected the downloaded Ubuntu ISO file as the optical disk.

I then started the virtual machine. The Ubuntu installation screen appeared, so I selected Install Ubuntu and followed the instructions shown on the screen.

I created my username and password when prompted. I selected the option to install Ubuntu on the virtual disk and started the installation.

After waiting for the installation to finish, I restarted the virtual machine. Ubuntu then booted successfully, and I was able to use Ubuntu through Oracle VirtualBox.
